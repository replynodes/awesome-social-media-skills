# Example: Research a Niche and Build a Content Calendar

Goes from "we want to post about X" to a validated, dated content calendar
— grounded in real audience signal rather than guesswork.

## Skills used, in order

1. [Audience Pain-Point Researcher](../../skills/research/audience-pain-point-researcher.md)
2. [Content Pillar Generator](../../skills/content-strategy/content-pillar-generator.md)
3. [Brand Voice Extractor](../../skills/content-strategy/brand-voice-extractor.md)
4. [Content Calendar Planner](../../skills/content-strategy/content-calendar-planner.md)
5. [Content Brief Generator](../../skills/content-strategy/content-brief-generator.md)

## Walkthrough

**1. Research the audience.** Gather real source material — forum threads,
reviews, support tickets, interview notes — and run
[Audience Pain-Point Researcher](../../skills/research/audience-pain-point-researcher.md).
This produces a ranked list of actual pain points, not assumed ones.

**2. Define pillars.** Feed the ranked pain points into
[Content Pillar Generator](../../skills/content-strategy/content-pillar-generator.md)
along with a description of the business or creator. This returns 3-5
content pillars, each tied to real audience signal rather than generic
category guesses.

**3. Establish voice.** In parallel, run
[Brand Voice Extractor](../../skills/content-strategy/brand-voice-extractor.md)
on existing content samples, if any exist, so every downstream writing
skill has a consistent tone to work from.

**4. Build the calendar.** Feed the pillars, target platforms, and desired
cadence into [Content Calendar Planner](../../skills/content-strategy/content-calendar-planner.md).
This distributes topics across dates according to the pillar mix, flagging
any key dates (launches, events) that still need a specific topic.

**5. Brief each slot.** As each calendar slot approaches, expand it with
[Content Brief Generator](../../skills/content-strategy/content-brief-generator.md)
into a full angle, key points, and format before handing it to a writing
skill.

## Result

A dated calendar where every slot traces back to a real pain point, a
defined pillar, and a specific angle — rather than a list of topics picked
because they "felt right" that week.

## Next step

Once posts from this calendar are published, close the loop with
[Performance Insight Analyzer](../../skills/analytics/performance-insight-analyzer.md)
to check whether the pillar mix is actually working, and feed adjustments
back into the next calendar cycle.
