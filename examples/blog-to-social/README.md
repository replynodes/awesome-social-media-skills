# Example: One Blog Post Into a Full Content Spread

Turns a single article into a thread, a LinkedIn post, and a carousel —
each built from the article's actual argument, not a superficial rewrite.

## Skills used, in order

1. [Blog-to-Multi-Platform Repurposer](../../skills/repurposing/blog-to-multi-platform-repurposer.md)
2. [X Thread Creator](../../skills/writing/x-thread-creator.md)
3. [LinkedIn Thought-Leadership Writer](../../skills/writing/linkedin-thought-leadership-writer.md)
4. [Carousel Content Designer](../../skills/images/carousel-content-designer.md)
5. [Content Claim Verifier](../../skills/research/content-claim-verifier.md)
6. [Content Quality Reviewer](../../skills/publishing/content-quality-reviewer.md)

## Walkthrough

**1. Extract.** Run [Blog-to-Multi-Platform Repurposer](../../skills/repurposing/blog-to-multi-platform-repurposer.md)
on the article. It returns the core argument plus 3-5 supporting ideas, each
tagged with the format it fits best — a thread candidate, a single-post
candidate, or a carousel/process candidate.

**2. Write the thread.** Feed the core argument and its supporting ideas
into [X Thread Creator](../../skills/writing/x-thread-creator.md) for the
ideas tagged as thread-worthy.

**3. Write the LinkedIn post.** Feed the core argument into
[LinkedIn Thought-Leadership Writer](../../skills/writing/linkedin-thought-leadership-writer.md)
for a standalone treatment — not the same text as the thread, restructured
for LinkedIn's format and reading pattern.

**4. Design the carousel.** For any idea tagged as a process or comparison
(a common shape for carousels), run [Carousel Content Designer](../../skills/images/carousel-content-designer.md)
to outline the slide sequence.

**5. Verify.** Run [Content Claim Verifier](../../skills/research/content-claim-verifier.md)
on all three outputs against the original article — the extraction step
preserves claims accurately, but any rewriting downstream (steps 2-4) is
worth re-checking, especially for numbers.

**6. Review and queue.** Each piece goes through
[Content Quality Reviewer](../../skills/publishing/content-quality-reviewer.md)
independently before publishing, since each was adapted differently.

## Result

One article → a thread, a LinkedIn post, and a carousel outline, each
structured for how that platform is actually read rather than copy-pasted
from the source.
