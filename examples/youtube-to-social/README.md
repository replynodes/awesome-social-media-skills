# Example: One YouTube Video Into a Week of Posts

Turns a single long-form video into a week's worth of platform-native
content, without losing accuracy on any claims made in the video.

## Skills used, in order

1. [YouTube-to-Social Repurposer](../../skills/repurposing/youtube-to-social-repurposer.md)
2. [Social Content Idea Validator](../../skills/research/social-content-idea-validator.md)
3. [Multi-Platform Content Adapter](../../skills/repurposing/multi-platform-content-adapter.md)
4. [Content Claim Verifier](../../skills/research/content-claim-verifier.md)
5. [Content Calendar Planner](../../skills/content-strategy/content-calendar-planner.md)
6. [Content Quality Reviewer](../../skills/publishing/content-quality-reviewer.md)

## Walkthrough

**1. Extract ideas.** Feed the video's transcript into
[YouTube-to-Social Repurposer](../../skills/repurposing/youtube-to-social-repurposer.md).
It returns 5-7 standalone ideas — not a single summary — each tagged with a
suggested format.

**2. Screen the ideas.** Run each extracted idea through
[Social Content Idea Validator](../../skills/research/social-content-idea-validator.md).
Ideas that only make sense with the full video's context, or that duplicate
each other, get dropped or flagged here rather than wasting a writing pass.

**3. Adapt per platform.** For ideas targeting multiple platforms, run
[Multi-Platform Content Adapter](../../skills/repurposing/multi-platform-content-adapter.md)
to produce platform-native versions — a thread for X, a text post for
LinkedIn, a caption for Instagram — instead of posting identical text
everywhere.

**4. Verify claims survived compression.** This is the step that's easy to
skip and shouldn't be: run [Content Claim Verifier](../../skills/research/content-claim-verifier.md)
against the original transcript. Numbers and specific claims can get
distorted when a 20-minute video is compressed into a 280-character post —
this step catches that before it publishes.

**5. Schedule.** Feed the validated, adapted ideas into
[Content Calendar Planner](../../skills/content-strategy/content-calendar-planner.md)
to spread them across the week rather than posting them all at once.

**6. Review before publishing.** Every piece still goes through
[Content Quality Reviewer](../../skills/publishing/content-quality-reviewer.md)
before it's queued — repurposed content needs the same review as anything
written from scratch.

## Result

One video → typically 5-7 pieces of distinct, verified, platform-native
content spread across a week, instead of one re-shared link or a single
generic summary post.
