# Engagement and Community

Skills for making sense of community response and drafting (not auto-
sending) replies.

| Skill | What it does |
|---|---|
| [Comment Theme Analyzer](comment-theme-analyzer.md) | Groups raw comments into recurring, actionable themes |
| [Reply Suggestion Assistant](reply-suggestion-assistant.md) | Drafts reply suggestions in brand voice, for human review |

## Typical order

Comments → [Comment Theme Analyzer](comment-theme-analyzer.md) →
[Reply Suggestion Assistant](reply-suggestion-assistant.md) → human review and send

Both skills are designed for a human-in-the-loop workflow — neither is
intended to auto-post replies without review. Recurring themes here are
also useful input to [Audience Pain-Point Researcher](../research/audience-pain-point-researcher.md).
