# Research

Skills for grounding content in real audience signal and verified facts,
before ideas get written or claims get published.

| Skill | What it does |
|---|---|
| [Audience Pain-Point Researcher](audience-pain-point-researcher.md) | Synthesizes ranked pain points from raw audience source material |
| [Social Content Idea Validator](social-content-idea-validator.md) | Screens an idea for relevance, specificity, differentiation, and evidence |
| [Content Claim Verifier](content-claim-verifier.md) | Checks a draft's factual claims against source material |
| [Jev Social Research](jev-social-research.md) | Captures source-linked Instagram, TikTok, or LinkedIn evidence through bounded Jev decisions and the local `socai` CLI |

## Typical order

[Audience Pain-Point Researcher](audience-pain-point-researcher.md) →
[Social Content Idea Validator](social-content-idea-validator.md) →
writing skill → [Content Claim Verifier](content-claim-verifier.md) →
[Content Quality Reviewer](../publishing/content-quality-reviewer.md)

These skills work from provided source material only — none of them
generate claims or pain points from general knowledge, since that would be
unverifiable. See [docs/use-cases.md](../../docs/use-cases.md) for full
workflow examples.
