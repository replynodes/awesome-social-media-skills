# Content Strategy

Skills for deciding what to create before anything gets written: brand
voice, content pillars, calendars, briefs, and launch planning.

| Skill | What it does |
|---|---|
| [Brand Voice Extractor](brand-voice-extractor.md) | Turns sample content into a reusable tone/voice profile |
| [Content Pillar Generator](content-pillar-generator.md) | Produces 3-5 recurring content themes from a brand description |
| [Content Calendar Planner](content-calendar-planner.md) | Schedules pillars into a dated, platform-aware calendar |
| [Content Brief Generator](content-brief-generator.md) | Expands a calendar topic into a full writing brief |
| [Product Launch Content Planner](product-launch-content-planner.md) | Plans coordinated launch-day and post-launch content |

## Typical order

[Brand Voice Extractor](brand-voice-extractor.md) →
[Content Pillar Generator](content-pillar-generator.md) →
[Content Calendar Planner](content-calendar-planner.md) →
[Content Brief Generator](content-brief-generator.md) → a writing skill

See also [Audience Pain-Point Researcher](../research/audience-pain-point-researcher.md)
for feeding real audience data into pillar and topic decisions, and
[docs/use-cases.md](../../docs/use-cases.md) for full worked examples.
