# Content Repurposing

Skills for turning one piece of content (a video, an article) into multiple
platform-ready pieces without losing accuracy or forcing weak adaptations.

| Skill | What it does |
|---|---|
| [YouTube-to-Social Repurposer](youtube-to-social-repurposer.md) | Extracts standalone content ideas from a video transcript |
| [Blog-to-Multi-Platform Repurposer](blog-to-multi-platform-repurposer.md) | Extracts standalone ideas from a blog post or article |
| [Multi-Platform Content Adapter](multi-platform-content-adapter.md) | Adapts one idea into platform-native versions across targets |

## Typical order

Source content → [YouTube-to-Social Repurposer](youtube-to-social-repurposer.md)
or [Blog-to-Multi-Platform Repurposer](blog-to-multi-platform-repurposer.md) →
[Multi-Platform Content Adapter](multi-platform-content-adapter.md) →
[Content Claim Verifier](../research/content-claim-verifier.md) →
[Cross-Platform Publishing Formatter](../publishing/cross-platform-publishing-formatter.md)

See [examples/youtube-to-social](../../examples/youtube-to-social/README.md)
and [examples/blog-to-social](../../examples/blog-to-social/README.md) for
full walkthroughs.
