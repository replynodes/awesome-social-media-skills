# Analytics and Optimization

Skills for closing the loop from published content back into what to create
next — grounded in provided performance data, not speculation.

| Skill | What it does |
|---|---|
| [Social Post Experiment Designer](social-post-experiment-designer.md) | Designs a structured, single-variable content experiment |
| [Performance Insight Analyzer](performance-insight-analyzer.md) | Surfaces specific, sample-sized patterns from performance data |
| [Weekly Content Review Agent](weekly-content-review-agent.md) | Recurring digest: what published, how it did, what to adjust |

## Typical order

Publish → [Performance Insight Analyzer](performance-insight-analyzer.md) →
[Social Post Experiment Designer](social-post-experiment-designer.md) (to
confirm a pattern deliberately) → adjustments feed back into
[Content Calendar Planner](../content-strategy/content-calendar-planner.md)

[Weekly Content Review Agent](weekly-content-review-agent.md) wraps this
loop into a recurring cadence rather than running it ad hoc.
