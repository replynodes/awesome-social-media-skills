# Images and Creative

Skills for structuring visual and carousel content. These skills produce
outlines, layout specs, and image-generation prompts — not final rendered
images.

| Skill | What it does |
|---|---|
| [Carousel Content Designer](carousel-content-designer.md) | Structures a topic into a slide-by-slide carousel outline |
| [Social Graphic Prompt Builder](social-graphic-prompt-builder.md) | Turns a single quote/stat/announcement into a graphic spec and image-generation prompt |

## Which one to use

Multiple related points or a process → [Carousel Content Designer](carousel-content-designer.md).
One quote, stat, or announcement → [Social Graphic Prompt Builder](social-graphic-prompt-builder.md).

If you're building or using a different image-generation skill (thumbnails,
brand visuals, product photography), see [CONTRIBUTING.md](../../CONTRIBUTING.md)
to add it here.
