# Images and Creative

Skills for structuring visual and carousel content. These skills produce
outlines and per-slide/per-image direction — not final rendered images.

| Skill | What it does |
|---|---|
| [Carousel Content Designer](carousel-content-designer.md) | Structures a topic into a slide-by-slide carousel outline |

This category is intentionally small today — visual content structure
overlaps heavily with [repurposing](../repurposing/) and
[writing](../writing/). If you're building or using an image-generation
skill (prompt-to-image workflows for social graphics, thumbnails, or brand
visuals), see [CONTRIBUTING.md](../../CONTRIBUTING.md) to add it here.
