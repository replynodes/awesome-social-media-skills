# Writing

Skills that turn a brief, idea, or raw account into finished, platform-native
copy.

| Skill | What it does |
|---|---|
| [LinkedIn Thought-Leadership Writer](linkedin-thought-leadership-writer.md) | Writes a LinkedIn post from a brief, in a given voice |
| [X Thread Creator](x-thread-creator.md) | Converts a brief or long-form idea into an X thread |
| [Founder Story Extractor](founder-story-extractor.md) | Pulls narrative structure from a raw founder account, without inventing details |

## Typical order

[Content Brief Generator](../content-strategy/content-brief-generator.md) →
a writing skill above → [Content Claim Verifier](../research/content-claim-verifier.md) →
[Content Quality Reviewer](../publishing/content-quality-reviewer.md)

For adapting one piece of writing across several platforms at once, see
[Multi-Platform Content Adapter](../repurposing/multi-platform-content-adapter.md)
rather than rewriting per platform from scratch.
