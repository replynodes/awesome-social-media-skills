# Video

Skills for planning and scripting short-form and long-form video content.

| Skill | What it does |
|---|---|
| [Short-Form Video Hook Generator](short-form-video-hook-generator.md) | Generates multiple opening-line candidates for a short-form video |
| [Video Script Writer](video-script-writer.md) | Writes a full script from a hook, key point, and supporting material |
| [Long-Form to Clips Planner](long-form-to-clips-planner.md) | Identifies clip-worthy moments in a long-form transcript, with timestamps |

## Typical order

**New video:** [Short-Form Video Hook Generator](short-form-video-hook-generator.md) →
[Video Script Writer](video-script-writer.md)

**Existing long-form video:** [Long-Form to Clips Planner](long-form-to-clips-planner.md)
to find the moments, then [Short-Form Video Hook Generator](short-form-video-hook-generator.md)
for a caption per clip.

For turning existing long-form video into *text* social posts (rather than
video clips), see [YouTube-to-Social Repurposer](../repurposing/youtube-to-social-repurposer.md)
in the [repurposing](../repurposing/) category.
