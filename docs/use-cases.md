# Use Cases

Concrete things people have built or can build by combining skills from this
repository. Each one links to the skills involved so you can assemble it
yourself.

[Multi-Platform Content Adapter](../skills/repurposing/multi-platform-content-adapter.md) →
[Content Quality Reviewer](../skills/publishing/content-quality-reviewer.md)
